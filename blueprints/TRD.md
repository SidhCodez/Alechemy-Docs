```markdown
# TRD.md
## Alchemy Docs — Technical Requirements Document

### 1. System Overview
Alchemy Docs is a two-part platform designed to host multiple prompt-driven frameworks.
1. **Documentation Platform (`/docs`):** A static site generated by mdBook that hosts "Hackathon Alchemy" (and future frameworks like "Builder Alchemy").
2. **Landing Page (Root `/`):** A marketing/introductory page that explains the Alchemy Docs brand and routes users to the documentation.

The current phase focuses entirely on building the **Documentation Platform**. The Landing Page will be integrated in Phase 2, but the architecture is designed now to accommodate both.

### 2. Tech Stack Choice
- **Documentation Engine:** mdBook (Rust-based static site generator)
- **Content Format:** Markdown (`.md`)
- **Landing Page (Phase 2):** Next.js or plain HTML/CSS
- **Hosting:** Vercel
- **Version Control:** GitHub
- **CI/CD:** GitHub Actions + Vercel Auto-Deploy

### 3. Repository Structure
The repository will support the main platform, the current framework, and future frameworks.

```text
alchemy-docs/
├── README.md                    # Main repo overview
├── vercel.json                  # Vercel routing configuration
│
├── landing/                     # (Phase 2) Landing page files
│   └── index.html
│
└── docs/                        # (Phase 1) mdBook documentation platform
    ├── book.toml                # mdBook configuration (Main platform)
    ├── SUMMARY.md               # Sidebar navigation (All frameworks)
    └── src/                     # Content (Markdown files)
        ├── introduction.md      # Alchemy Docs welcome
        │
        ├── hackathon-alchemy/   # Sub-product 1: Hackathon Alchemy
        │   ├── README.md        # Framework overview
        │   ├── 01-AI-ML/
        │   ├── 02-Non-AI/
        │   └── ... (20 categories)
        │
        └── builder-alchemy/     # Sub-product 2: Builder Alchemy (Future)
            └── README.md
```

### 4. Documentation Engine Requirements (mdBook)
- **Version:** Latest stable release.
- **Installation:** Rust toolchain required (`cargo install mdbook`).
- **Configuration (`book.toml`):**
  - Title: Alchemy Docs
  - Authors: Siddiq
  - Description: The ultimate prompt framework for hackathons, builders, and creators.
  - Search: Enabled (built-in elasticlunr.js)
  - Theme: Custom (based on Alchemy brand colors)
- **Navigation (`SUMMARY.md`):** 
  - **Top-level sections** for each framework (Hackathon Alchemy, Builder Alchemy).
  - **Sub-level items** for the 20 categories under Hackathon Alchemy.
  - **Nested items** for the 4 phases under each category.
- **Content Path:** `docs/src/hackathon-alchemy/` will contain the 330+ `.md` files.

### 5. Landing Page Requirements (Phase 2)
- **Route:** `/` (root)
- **Purpose:** Explain Alchemy Docs, showcase frameworks, CTA to `/docs`.
- **Framework:** Next.js or plain HTML (TBD).
- **Hosting:** Vercel serves the landing page at root and rewrites `/docs` to the mdBook output.

### 6. Integration & Automation Requirements
- **GitHub Actions Workflow:**
  - Trigger: Push to `main` branch.
  - Step 1: Install Rust.
  - Step 2: Install mdBook (`cargo install mdbook`).
  - Step 3: Build documentation (`mdbook build docs`).
  - Step 4: Deploy to Vercel (or Vercel handles this automatically).
- **Vercel Configuration:**
  - `vercel.json` will define rewrite rules:
    - `/` → Landing page (Phase 2)
    - `/docs/*` → mdBook output (`docs/book/`)

### 7. Environment & Dependencies
- **Runtime:** Node.js (for Vercel), Rust (for mdBook build).
- **Packages:** `mdbook` (Cargo package).
- **No databases, no backend APIs.**

### 8. Performance Requirements
- **Lighthouse Score:** > 95 across all categories.
- **Load Time:** < 1 second for documentation pages.
- **Search Response:** < 200ms for local search queries.
- **Build Time:** < 5 minutes on Vercel.

### 9. Security Requirements
- No API keys or secrets in the repository.
- All content is public and static.
- HTTPS enforced by Vercel.
- No user authentication, cookies, or tracking.

### 10. Testing Requirements
- **Local Build Test:** `mdbook serve` runs without errors.
- **Link Check:** No broken links in `SUMMARY.md`.
- **Content Check:** All 330+ documents render correctly.
- **Search Check:** Search returns relevant results for key terms.
- **Mobile Check:** Site works on all breakpoints.

### 11. Deployment Requirements
- **Platform:** Vercel (free tier).
- **Build Command:** `mdbook build docs`
- **Output Directory:** `docs/book`
- **Custom Domain:** TBD (e.g., `alchemy-docs.vercel.app`).
- **Rollback Strategy:** Vercel's built-in rollback.

### 12. Maintenance & Scalability Requirements
- **Adding a new framework:** Create a new folder under `docs/src/`, add `.md` files, update `SUMMARY.md`, push to GitHub.
- **Updating content:** Edit the `.md` file → Push → Auto-deploy.
- **Adding a new category to Hackathon Alchemy:** Create a folder, add 4-phase docs, update `SUMMARY.md`, push.
