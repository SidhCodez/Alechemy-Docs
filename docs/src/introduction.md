# Welcome to Alchemy Docs

> **The ultimate prompt framework for hackathons, builders, and creators.**

Welcome to **Alchemy Docs** — a documentation platform hosting production-grade prompt frameworks designed to help developers, designers, and founders build software rapidly and methodically.

Instead of navigating unstructured repositories and raw files, **Alchemy Docs** provides a unified, searchable, and responsive reading experience powered by a **Docs-as-Code** architecture.

---

## 🧭 Frameworks in Alchemy Docs

### 🏆 Hackathon Alchemy (Active Launch)
**Hackathon Alchemy** is a complete taxonomy of 20 hackathon categories and over 330 structured document prompt packs. Built for fast-paced 24–48 hour sprints, each category provides step-by-step prompts to guide your project from problem validation to final presentation:

- **Phase 1: Problem Definition & Strategy** — Problem Analysis, PRD, and TRD.
- **Phase 2: Technical Blueprint** — Architecture, Schemas, APIs, Rules, and Systems.
- **Phase 3: Execution, Quality & Security** — UI Specs, Error Handling, Security, Testing, and Evaluation.
- **Phase 4: Delivery & Presentation** — Deployment, Demo Scripts, and Glossaries.
- **Unique Deep Dives** — 6 Debugging Pillars, 8 System Design Dimensions, 8 SEO Pillars, and 10 Scalability Layers.

👉 **[Explore Hackathon Alchemy](hackathon-alchemy/README.md)** | **[How to Use This Framework](hackathon-alchemy/how-to-use.md)**

## ⚡ Key Features

- **🔍 Global Instant Search:** Press `/` or click the search bar at any time to query across all 330+ documents and prompt packs.
- **📋 One-Click Copy Prompts:** Every prompt block is ready to copy straight into your AI workspace (ChatGPT, Claude, Cursor, Copilot, Gemini).
- **🌓 Dark & Light Modes:** Custom themes engineered for readability and high contrast.
- **📱 Fully Responsive:** Clean reading experience across mobile phones, tablets, and desktop workstations.
- **🛠️ Docs-as-Code:** 100% version-controlled Markdown deployed to a global edge CDN.
