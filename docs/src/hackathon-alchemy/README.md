# Hackathon Alchemy

Welcome to **Hackathon Alchemy** — a prompt engineering and document framework designed to help hackers, developers, and founders build production-grade prototypes during high-pressure 24–48 hour events.

Whether you're developing an AI agent, a no-code workflow, or a Web3 smart contract, this framework gives you pre-tested prompt packs to plan, architect, build, and deliver your project methodically.

---

## 🏗️ The 4-Phase Workflow (Categories 01–16)

Every standard category is divided into 4 sequential phases:

```text
┌─────────────────────────────────┐
│  Phase 1: Problem Definition   │  Problem Analysis ➔ PRD ➔ TRD
└────────────────┬────────────────┘
                 ▼
┌─────────────────────────────────┐
│  Phase 2: Technical Blueprint   │  System Architecture ➔ Schemas ➔ APIs
└────────────────┬────────────────┘
                 ▼
┌─────────────────────────────────┐
│  Phase 3: Execution & Quality   │  UI Spec ➔ Error Handling ➔ Security ➔ Testing
└────────────────┬────────────────┘
                 ▼
┌─────────────────────────────────┐
│  Phase 4: Delivery & Demo       │  Deployment ➔ Demo Script ➔ Glossary
└─────────────────────────────────┘
```

1. **Phase 1: Problem Definition & Strategy**  
   Understand the user's actual problem before writing code. Produce clear `PROBLEM_ANALYSIS.md`, `PRD.md`, and `TRD.md` to align the team and avoid scope creep.
2. **Phase 2: Technical Blueprint**  
   Define system architectures, data models, APIs, and domain-specific rules (like AI rules or smart contracts).
3. **Phase 3: Execution, Quality & Security**  
   Prepare UI specs, robust error handling, security guardrails, QA testing checklists, and evaluation metrics.
4. **Phase 4: Delivery & Presentation**  
   Configure continuous deployment, rehearse a winning demo pitch script, and define a glossary for judges.

## 🔍 Specialized Deep-Dive Categories (17–20)

For complex engineering disciplines beyond the 4-phase model, Hackathon Alchemy includes dedicated non-linear frameworks:

- **17. Debugging (6 Pillars):** Detect & Define ➔ Reproduce & Isolate ➔ Instrument & Observe ➔ Hypothesize & Test ➔ Resolve & Verify ➔ Prevent & Learn.
- **18. Improve System Design (8 Dimensions):** Requirements, Component Map, Data Modeling, Communication Protocols, Partitioning, Fault Tolerance, Observability, and Trade-offs.
- **19. SEO Optimization (8 Pillars):** Technical Foundation, On-Page Optimization, Content Strategy, Keyword Architecture, Off-Page Authority, Geo-targeting, UX Signals, and Measurement.
- **20. Scalability (10 Layers):** Baseline Capacity, Vertical Scaling, Horizontal Scaling, Data Layer, Caching, Async Queues, Cost Optimization, Resilience, Multi-Region, and Governance.
